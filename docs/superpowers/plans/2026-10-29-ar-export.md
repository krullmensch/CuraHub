# AR-Export Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Every published exhibition version gets a GLB + USDZ of works and room, built by headless Chromium on the server and opened from the public viewer with one tap.

**Architecture:** An in-process job queue (pattern of `bookJobs.ts`) launches Chromium over CDP, which opens a token-protected export page of the built app; the page renders the version with the viewer's own components in an export mode, runs three's `GLTFExporter`/`USDZExporter` and uploads both files. A new `ArExport` table holds status and file names; public, editor and job routes sit on top.

**Tech Stack:** Express 5 + Prisma 5 (MySQL), Jest/supertest; React 19 + R3F + three 0.186, Vitest; Chromium (Alpine `chromium` package) driven over `--remote-debugging-pipe`.

**Spec:** `docs/superpowers/specs/2026-10-29-ar-export-design.md`

## Global Constraints

- Branch `feat/ar-export` (on top of `feat/published-version-lock`). Never push, merge or touch production.
- Never run the app, a dev server, MySQL or Chromium locally (project rule). Allowed locally: `npm run test`, `npm run lint`, `npx tsc -b`, `npm run build`, `cd server && npm test` (DB-backed suites skip without a DB), `cd server && npm run build`. App and DB verification happens on the test stack (Task 10).
- Migrations are written by hand (no `prisma migrate dev` locally): `server/prisma/migrations/20261030120000_ar_export/migration.sql`, then `npx prisma generate`.
- Public viewer path is `/exhibition/:slug` (spec text corrected).
- File storage: `<uploads>/.ar/<versionId>-<random>.glb|.usdz` (`random` = 12 hex chars from `crypto.randomBytes(6)`).
- Limits: texture longest side 2048 px, rerun at 1024 px when a file > 80 MB (`80 * 1024 ** 2`), fail when > 150 MB; job timeout 5 min (SIGKILL); job token valid 10 min.
- MIME: `model/gltf-binary`, `model/vnd.usdz+zip`; public files `Cache-Control: public, max-age=31536000, immutable`.
- Job token: HMAC-SHA256 with an in-memory random secret (never `JWT_SECRET`), carried in the URL fragment `#token=…`, sent by the page as `Authorization: Bearer <token>`.
- Live event: extend `VersionEvent` with `'arExport'` (server `live/protocol.ts` and client mirror).
- German strings, verbatim:
  - Viewer button: „In AR ansehen"; while preparing: „AR wird vorbereitet…"; `?ar=1` button: „In AR öffnen"
  - QR dialog title „Auf dem Handy öffnen", text „Scanne den Code mit dem Handy, um die Ausstellung in echter Größe in deinem Raum zu sehen."
  - Editor row label „AR-Export"; states „In Warteschlange (Platz N)", „Wird erzeugt…", „Fertig · GLB 12 MB · USDZ 14 MB" (sizes formatted in MB, no decimals below 10 MB → one decimal), „N Werke ausgelassen" (1 → „1 Werk ausgelassen"), „Fehlgeschlagen: <error>"
  - Buttons „GLB herunterladen", „USDZ herunterladen", „Neu erzeugen"
  - Errors: „Chromium nicht installiert", „Zu groß für AR", timeout „Zeitüberschreitung beim Export"
  - System check label „AR-Export (Chromium)"
- Commits end with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

## Review Focus

1. Republishing while a job runs → the finished files of the now-unpublished version must not be stored or served; the new version's job runs next (Task 4 test `discards result when version no longer published`).
2. Exhibition/project deleted (rows cascade, no route hook) → files in `.ar/` must not stay forever (Task 1 `pruneOrphanArFiles` at start, test `removes files without a row`).
3. iPadOS Safari reports a desktop Mac UA → must still get Quick Look, not the QR dialog (Task 8 test `iPadOS desktop UA with touch is ios`).
4. A version with zero instances (empty room) → export still succeeds with the room only (Task 6 test `room-only scene exports`).
5. A broken/missing artwork file → export completes with `skipped` count instead of hanging until the 5-min timeout (Task 7: load-settle counts failed sources; Task 4 test stores `skipped`).
