# Ausstellungs- & Projektverwaltung

In CuraHub verwaltest du deine Ausstellungen in Projekten. Das System nutzt eine Versionskontrolle, damit du verschiedene Entwürfe sicher ausprobieren kannst.

## Projekt-Dashboard
Auf deinem Dashboard siehst du alle deine Projekte. Jedes Projekt kann mehrere Ausstellungen beinhalten.

## Versionskontrolle
Eine Version ist ein kompletter Snapshot (Speicherpunkt) deiner Ausstellung, inklusive aller platzierten Kunstwerke und Wände.
- **Branching:** Wenn mehrere Kuratoren zusammenarbeiten, kann jeder basierend auf einer Version weiterarbeiten.
- **Historie laden:** Über das Version Panel im Editor kannst du jederzeit zu einer älteren Version zurückkehren.

## Publishing-Workflow
Damit Besucher deine Ausstellung sehen können, muss sie veröffentlicht werden.
1. Wähle eine fertige Version im Version Panel aus.
2. Markiere diese Version als **"published"**.
3. Besucher können nun über den Ausstellungs-Link (`/exhibition/:slug`) darauf zugreifen.

*Tipp: Admins können besonders gelungene, veröffentlichte Ausstellungen auf der Startseite hervorheben (Featured Exhibitions).*
